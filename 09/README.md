# React Data Explorer — Static Starter Template

## اجرا

ابتدا داخل پوشه پروژه:

```bash
npm install
npm run dev
```

سپس آدرسی که Vite نمایش می‌دهد، معمولاً:

```text
http://localhost:5173
```

را در مرورگر باز کنید.

> فایل `index.html` را مستقیم با دوبار کلیک باز نکنید.
> پروژه React/Vite باید با `npm run dev` اجرا شود.

## نسخه‌های استفاده‌شده

- React 18
- Vite 5
- React Router 6
- Tailwind CSS 3

## هدف آموزشی

این نسخه فقط UI و داده استاتیک دارد.

موارد زیر عمداً هنوز پیاده‌سازی نشده‌اند:

- API
- useEffect
- Pagination logic
- Infinite Scroll logic
- useRef
- useCallback
- IntersectionObserver
- debounce
- useMemo
- AbortController
- loading/error logic
